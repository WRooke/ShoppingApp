2. Push — sending

Terse, four stages: Reading your list → Sending (n of N) → Confirming → Done. Each item just shows its name with the existing spinner/tick icons (no 'Adding…/Added…' sentences). The list scrolls inside itself so the Push button never leaves the screen. Items are tracked by checklist row, so the ticks always line up (today they never do).

3. Push — confirming

The new real step: after the last item is sent, the app re-reads the AnyList list and checks every item is there, uncrossed, with the right amount. Nothing is called 'done' until this passes. Any retries happen here.
